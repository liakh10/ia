Parameters and fees

All windows and delays are counted in slots from on-chain events (a slot is about 0.4 s, so durations below are approximate). A test copies the parameters when it opens and runs under them; a change applies from the next test, except the surety, draw, spill, league and rotation rules, which apply at once.

Fees#

  • The program fee is the treasury's 5% share of each plant price, withdrawn by the admin to the dev wallet. A wallet holding at least 1,000,000 $IA pays none.
  • The runner fund (12%) pays inference bills and transaction fees, in public draws capped per test.
  • $IA is a plain token with no other role in the program; its creator fees go to the dev.
  • There is no fee on surety deposits or withdrawals, and none on claims or forecasts.
  • No dev capital sits in any purse, fund or bounty.
