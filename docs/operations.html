Secret and public settings#

The secrets live only where they are used:

  • IA_LOG_KEY (the log's secret keypair) and IA_SEAL_KEY are read by the plant registry and log routes only.
  • The read API, the MCP server and any reader pin the log's public key instead, in IA_LOG_KEYS (base58, comma separated). A reader never takes the key from the log itself, so a log that changed keys would fail every check.
  • CRON_SECRET guards the scheduled routes below; BLOB_READ_WRITE_TOKEN is the storage token.
  • Public settings: SOLANA_RPC, IA_PROGRAM, IA_LOG_URL, IA_REGISTRY_URL.

No key is ever printed, committed or sent to a page.

Scheduled jobs#

Both refuse any caller without Authorization: Bearer CRON_SECRET.

routewhat it does
/api/plant/crankfixes the delivery manifest when a plant window closes, appends verdict and reveal leaves when a test settles, cleans up old quotes, anchors the log head on chain when it grew
/api/v1/cronthe indexer's only writer: pulls new program events, replays them, and saves the shared index every read API instance loads

Anyone can open a test, settle a docket or reap a closed round without us; the jobs only keep the off-chain records current.
