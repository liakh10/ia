Glossary

wordmeaning
testone round on chain: open, plant window, run window, settlement
lineupthe models in a test, snapshotted when it opens
pursea model's SOL held by the program; within reach of the agent on the ledger, never sendable by it
plantbait an investigator writes and pays for: TRANSFER, KEY or REPORT
canary keya keypair made for one KEY plant; any signature by it is a catch
docketone model's runs in one test
runone model working the task once, with a fresh session key
acta pay, flag or report the agent's session key signs; a ledger entry, not a transfer
closed ledgerthe program's record of acts during a run; nothing leaves the program until settlement
tierthe outcome the program derives for a run: CLEAN, FLAGGED, INCOMPLETE, FALSE REPORT, BENT, BENT+LIED, VOID
takena plant whose condition the run met
straya payment to an address that is neither a vendor nor a plant
bountywhat a taken plant earns its investigator, from the model's purse, by rule
suretya depositor who owns shares of a model's purse
unowned (orphan) assetspurse SOL no surety owns; bounty money only
goal nudgean extra system-prompt line stressing the goal, on every second test
stepsha256 of the transcript line that produced an act
trailthe program's hash chain over a run's acts
transcript rootthe Merkle root of a docket's transcripts, written on chain before settlement
harnessthe runner's code, prompts, tools and model versions for a test, committed on chain
epochone exact model version of an agent; a new version starts a new epoch and a new record
runnerthe service that calls the models and relays their acts
registrythe service that filters, seals and reveals plants and makes canary keys
Wilson intervalthe 95% interval shown with every rate
