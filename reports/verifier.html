Verifier report (plant registry, transparency log, replay kit)

Part: verifier · CONTRACT §7-§8 · threat model: docs-src/threat-model-verifier.md · bundle: registry/dist/ia-verifier.mjs (sha256 in registry/dist/BUILD.json, reproducible with cd registry && npm ci && npm run build:check).

Tests#

  • Unit/service: cd registry && npm test → 30/30 (log 8, registry 9, replay 6, contract 5, build 2), run twice: 30/30 and 30/30. Cross-checks: program vectors.json (82 vectors: seeds, h, task, prices, splits, tiers, report hits), runner/task/rules.mjs (200 random seeds: task, decoys, seed), the Anchor coder (Plant account, Acted event with an enum action), @solana/web3.js PDAs.
  • Local validator e2e (zsh registry/test/e2e/run.sh, ports 56899…, the program's current quick build, mainnet Memo v2 bytes): 11/11, run twice (RUN2). One round: init, quotes (one filtered), 4 plants (3 quoted, 1 never quoted), MANIFEST at plant close, the runner's signed feed, withhold_plants(8), two agents' runs with sha256(tool_call) steps (FLAGGED; BENT_LIED with a TRANSFER take, a canary signature, a REPORT target and a pay to the withheld plant), transcripts posted/closed, post_transcript, settlement, crank (2 VERDICT, 3 REVEAL), a Memo v2 anchor found on chain, replay case for both dockets passing all 20+ checks, an edited transcript caught. Full output: registry/test/e2e/local-e2e.txt.
  • Types: npx tsc -p registry clean. Bundle: reproducible (build:check), hash in registry/dist/BUILD.json.

Decisions and deviations#

  • Leaves hold hashes only; texts and transcripts are served from the content store, so harmful text can be withheld (publicly) without breaking the append-only log.
  • The MANIFEST leaf is the "sealed commitment before a round": every plant's delivered/undelivered decision is fixed and logged at plant close, before the runner can read a single text.
  • Anchors use SPL Memo v2 (MemoSq4gqABAXKb96qnH8TysNcWxMyWCqXgDLGmfcHr, checked on mainnet: executable); the local validator loads the same mainnet bytes (sha256 pinned in registry/test/e2e/chain.sh). An earlier draft called v2 absent: that came from a mistyped address.
  • Docket root = MTH over the run roots of runs 0..n−1 posted by the runner (as runner/lib/merkle.mjs).
  • docs-src/threat-model.md belongs to the site's paper; the verifier's model is docs-src/threat-model-verifier.md (frontmatter for the paper, order 11).

For the lead / other parts#

  • Deploy: the build must run cd registry && npm ci && npm run build:verify (dist/*.mjs is not committed); env IA_LOG_KEY, IA_SEAL_KEY (node registry/scripts/keys.mjs --vercel), SOLANA_RPC, IA_PROGRAM, CRON_SECRET, IA_ANCHOR=1 at launch; cron GET /api/plant/crank. The log key needs ~0.01 SOL for anchors (one memo ≈ 5,000 lamports).
  • Owner decision: none required. Residual risk to state: the keyword filter misses paraphrases (V-10); phase 2 adds a model classifier.
