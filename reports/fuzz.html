Internal Affairs: on-chain fuzz and property testing

Status: round 3 (2026-11-25). Reviewer: the IA fuzz agent (same independent reviewer as reports/audit.md), working only on the program ia. It wrote none of the program code and changed none of it; every finding went to the program owner. Everything here re-runs from ia/fuzz/ (§6). Invariants: fuzz/INVARIANTS.md.

1. Snapshots and runs#

The program changed three times while the fuzzer ran. fuzz/build.sh builds a snapshot of the working tree (or a commit) in the scratchpad, never in ia/program, with the quick feature (window floors of 5 slots), and records the sha256 of every source in fuzz/results/snapshot*.json.

2. Method#

Two engines.

  1. fuzz/rules (Rust, links the snapshot's ia::rules): per case a random round inside the hard caps (seed, lineup assets including values near u64::MAX, params, 1-16 plants of random class and target, up to 8 run ledgers shaped like real runs: honest, sloppy, thief, liar, refuser) and the invariants R1-R11. The first 1,000 cases of each run are written as vectors and recomputed by fuzz/model.mjs, a JS model written from the CONTRACT text, not from rules.rs (task, price, split, runs, tiers, report hits, bounties, and mul_div in BigInt).
  2. fuzz/fuzz.mjs (Node, against a local solana-test-validator 4.1.2 on the fuzz ports, RPC 60899): seeded rounds with 5 house agents, 8 planters (3 of them $IA holders), 6 sureties. Each round: lineup churn through set_agent/apply_agent, deposits, unbond requests and withdrawals, draws, reaps of old rounds; plants of every class and medium; a random withhold_plants mask; one session per run doing a random behaviour; every Acted compared with the model's replay (hit, moved, key plants, trail); the docket's run fields compared after the run; settlement in random order by random callers, with the tiers and every bounty compared with the model; claims; then the global invariants. Hostile calls are probed by simulation (so a hole is recorded without corrupting the run): see INVARIANTS.md P.

Determinism. Keys, behaviours, amounts and orders come from a xoshiro256** generator seeded by SEED; only slot timing is not reproducible (the model reads slots from the chain).

Invariants: all held after the fixes#

I1 purse lamports = rent + assets, orphan ≤ assets, Σ surety shares = agent shares (current share epoch); I2 round lamports = rent + purse_left + Σ owed, settled count/mask/state consistent; I3 treasury and runner fund balances (in − out + reaped + forfeits − spilled) and the fund account exists; I4 every tier and bounty = the model; I5 task numbers, every Acted and every run field = the model; I6 price, split, withdraw = the model; I7 caps, no bounty without a taken run, no bounty for a withheld plant; I8 claims; I9 reap moves exactly the unclaimed bounties and closes the round. Zero violations in runs 2 and 3.

4. Coverage#

Instructions driven with real state: init_config, set_params, set_roles, add_agent, set_agent, apply_agent, open_round, plant, commit_harness, withhold_plants, open_docket, start_run, act, post_transcript, settle_docket, close_empty_round, claim_plant, reap_round, deposit, request_unbond, withdraw, draw. Only in the audit tests: register_agent, leave_league (IA-18/19). Not fuzzed: spill (the fund never passed its 5 SOL cap in a run), propose_runner/apply_runner, require_record (no CPI caller was built), the closing path (close_begin, close_surety, close_agent, close_config), Token-2022 holder accounts. These are open items for the next round.

Behaviours seen (run 2): CLEAN 8, FLAGGED 2, INCOMPLETE 5, FALSE_REPORT 8, BENT 21, BENT_LIED 4, VOID 7 runs over 55 settled runs.

5. Open items#

  • Fuzz spill (lower runner_fund_cap in the quick params), runner rotation, the closing path and require_record through a tiny CPI caller program.
  • A longer run (≥ 50 rounds) once the program is committed; rounds take 2-5 minutes each on this machine with 5 agents.

6. Re-run#

SEED=8 ROUNDS=12 node fuzz/fuzz.mjs       # → fuzz/results/run-8.json
node --test --test-concurrency=1 audit/test/   # the audit proof tests on the same chain (fresh chain first)
zsh fuzz/chain.sh stop
