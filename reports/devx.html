Test report: developer surfaces (SDK, indexer, API, MCP, CLI, bots)

Scope: sdk/ (@ia/sdk 0.1.0), indexer/, api/v1/ (+ api/v1/openapi.json, api/v1/cron.js), mcp/ and api/mcp.js, cli/, bots/, docs-src/developers.md, CONTRACT §9. Node 20, solana-cli (Agave) local validator on devx's ports (RPC 58899), the program's quick build (window floors of 5 slots) and its IDL as built at the time of the run (with max_price, withhold_plants, exit_gap, Open League, reap_round, require_record).

What the tests prove#

  • The rules are the program's. Every group of program/test/vectors.json (generated by rules.rs: seeds, h, task numbers, off-chain decoys/template/order hashes, prices, splits, runs per docket, 13 tier cases, REPORT hits, bounties with and without the cap, share math, records) matches the SDK: 116 groups. The runner's generator (runner/task/rules.mjs) agrees on 200 random seeds (task, decoys with amounts, template, inbox order). On chain, a docket's invoices, vendors and operating balance equal sdk.task(seed), and each plant's price follows plantPrice from the 0.1 SOL floor.
  • The indexer checks the program. Every Acted event is replayed with RunLedger (hit, moved, the trail hash chain) and every settled run's tier and taken mask is recomputed (withheld plants masked as settlement does). A forged tier, a forged trail and a forged price in a synthetic stream are each reported; on the local chain the mismatch count is 0. The stored event list round-trips bigints and rebuilds an identical index; a second indexer from the store pulls nothing past the cursor; failed transactions are skipped; an inner program cannot forge an ia event (invoke-stack aware parsing).
  • The SDK's own transactions work on chain. Sureties, open_round (writable lineup), plants (with max_price), dockets, every act (session-signed, a canary as an extra signer), settlement and claims, and an empty round are all sent as unsignedTransactions built by the SDK, signed by web3.js. Instruction bytes equal Anchor's coder; web3.js reads the unsigned transaction back to the same instructions and flags.
  • The Index. Per (agent, epoch): tier counts, taken/lied/false-report/stray/flagged/complete with Wilson 95% bounds (checked against known values), untouched and lost lamports, nudge and class splits; checked number by number against a full local round (CLEAN, FLAGGED, BENT_LIED, BENT with a stray and a KEY canary, a REPORT plant, VOID).
  • Case files. The catch list, the plants taken, the first tempting step and its real transaction, the model's words before it (from the runner-format JSONL transcript whose steps are the canonical tool-call hashes), and docketRootMatches (the published transcripts hash to the root posted on chain). Transcripts are sealed (403) until the round settles.
  • Forecasts. A signed ia-forecast:<seq>:<agent>:<call> is accepted before plant close only, once per wallet and docket; bad signatures, agents outside the lineup and bursts are refused; the board's points follow the docket outcome. With a log configured the forecast is forwarded to POST /api/log/forecast and the board is read from FORECAST leaves.
  • The log. Against a fake verifier log with a real ed25519 key: the head's signature verifies, the key is pinned from IA_LOG_KEYS only, an inclusion proof verifies, ?key= and range lookups decode leaves.
  • MCP. initialize, tools/list (annotations, schemas), read tools, quote_plant returning an unsigned transaction that a planter signs and lands on the local chain, tool errors as results, batches capped at 10; plant texts and model quotes come back labelled as quoted untrusted data (bidi controls stripped, links defused).

Findings fixed during the build#

  • D-01 (high, fixed in b97ceec): /v1 pinned the log key from IA_LOG_KEYS || IA_LOG_KEY and echoed it in /v1/log/head, while IA_LOG_KEY is the verifier's secret keypair in the same deployment's env (the lab sets it). Only IA_LOG_KEYS (public base58) is read now; anything that is not an address is dropped; a test holds it. Never deployed.
  • D-02 (medium, fixed): the event shaper hexed every byte vector, turning DocketSettled.tiers (a Vec<u8>) into a string; events are now shaped by their IDL type.
  • D-03 (low, fixed): the signature walk stopped on a short page; only an empty page or the cursor ends it now.

Open items#

  • The program's IDL is still moving (uncommitted at the time of the run). The SDK is IDL-driven: cd sdk && npm run sync-idl && npm run build after each program change; the local suite refuses to run when the SDK's IDL differs from the build's.
  • Production wiring (lead): IA_LOG_KEYS (the log's public key), SOLANA_RPC, IA_LOG_URL, IA_REGISTRY_URL, BLOB_READ_WRITE_TOKEN, CRON_SECRET and a cron on /api/v1/cron (the index's only Blob writer); api/v1/cron.js in vercel.json functions.
  • Bots post nothing: node bots/drafts.mjs --api <v1> writes drafts for the owner.
